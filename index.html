02 / UNDER THE HOOD

Not a movie.
A working model.

There are no pre-rendered frames here. Tensile calculates the forward pass, gradients and weight updates in JavaScript, then draws the result you see.

01

Forward pass

Inputs flow through weighted connections. Each neuron applies an activation function and passes its output forward.

z = Wx + b
02

Backpropagation

The model measures its error, then uses the chain rule to work out how each weight contributed to it.

∂L / ∂W
03

Weight update

The optimizer nudges the weights in a direction that should make the next prediction a little better.

W ← W − η∇L
