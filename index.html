02 / UNDER THE HOOD

Not a movie.
A working model.

There are no pre-rendered frames here. Tensile computes the forward pass, analytical backpropagation, and weight updates in JavaScript, then draws the decision contour in real time.

01

Forward pass

Input coordinates and polynomial transforms flow through weighted connections. Each neuron applies the chosen non-linearity (Tanh, ReLU, LeakyReLU, or Sigmoid).

z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]}
02

Backpropagation

Binary cross-entropy loss gradients propagate backwards using the chain rule to accumulate partial derivatives for every weight matrix and bias vector.

\delta^{[l]} = (W^{[l+1]T} \delta^{[l+1]}) \odot \sigma'(z^{[l]})
03

Optimizer step

Adam or SGD with momentum updates the parameters to minimize empirical risk while tracking train vs test generalization.

\theta \leftarrow \theta - \eta \cdot \hat{m}_t / (\sqrt{\hat{v}_t} + \epsilon)
